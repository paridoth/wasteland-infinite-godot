# Wasteland Infinite

Open-source isometric post-apocalyptic RPG: Diablo 2 Resurrected look, Fallout-style turn-based
AP combat and item-driven play, Dwarf Fortress-style generated history, LLM-driven NPCs.

- `game/` — Godot 4.7 project (`~/tools/godot --path game`)
- `director/history/` — seeded history + present-day NPC briefs (Python 3, no dependencies)
- `tests/` — `python3 -m unittest discover tests`
